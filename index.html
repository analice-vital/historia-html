História do HTML

O que é HTML?

HTML é uma linguagem de marcação utilizada para criar páginas web. Ela permite estruturar textos, imagens e links.

Principais versões do HTML

  • HTML 2.0 (1995)
  • HTML 3.2 (1997)
  • HTML 4.01 (1999)
  • XHTML 1.0 (2000)
  • HTML5 (2014)
